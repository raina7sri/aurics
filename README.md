# Aurics

**AI-native GTM tools, built in the open** — free, open-source tools for measuring and improving how brands show up in AI-driven search and go-to-market. Any brand, any category, any stage.

**Live:** https://raina7sri.github.io/aurics/ · [aurics.ai](https://aurics.ai)

## Tools

- **[AI Visibility Scorecard](https://github.com/raina7sri/ai-visibility-scorecard)** — measure how ChatGPT, Gemini, Perplexity & Claude recommend, mention & cite your brand. Open source, runs in your browser.
- **[Customer Response Engine](https://github.com/raina7sri/response-engine)** — an AI-native workflow for customer responses: AI reasoning applies an approved playbook, the human keeps the business-context decisions and the final send.
- **[Customer Proof AI Layer](https://github.com/raina7sri/customer-proof-ai-layer)** — turn transcripts and call notes into governed Customer Proof Records that Sales, CS, Marketing, Website and AR/PR can reuse safely. AI structures the proof; humans approve the claim scope.
